# Module 02 — LLM Serving & Acceleration

Focus: Serving large language models with high throughput and low latency.

Topics

- vLLM, Ollama: lightweight, high-performance LLM servers
- TensorRT-LLM and hardware acceleration (NVIDIA GPUs, Jetson/Edge) 
- Model quantization and INT8/FP16 optimization
- Inference patterns: batching, sharding, asynchronous streaming
- Deployment patterns: sidecars, canary rollouts, autoscaling

Deliverables

- Example vLLM and TensorRT-LLM deployment manifests
- Benchmarks and tooling for latency/throughput measurement
