# Module 01 — Cloud-Native Infrastructure & Containerization

Focus: Foundations of cloud-native infrastructure for AI workloads.

Topics

- Docker: images, multi-stage builds, best practices
- Kubernetes: pods, deployments, statefulsets, autoscaling
- Helm: packaging, charts, and deployment patterns
- Cluster provisioning: IaC examples (Terraform, CloudFormation)
- Networking, storage, and GPU provisioning in the cloud

Deliverables

- Reference K8s manifests and Helm charts for model serving
- Labs: containerizing a model server, deploying to a managed K8s cluster
